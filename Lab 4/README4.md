## Objective

The purpose of this practical work is to develop practical skills in data aggregation and grouping using the Pandas library in Python. The work also involves creating pivot tables, cross-tabulation tables and combining datasets using different methods.

## Dataset Description

The practical work uses the `specific_vehicles.csv` dataset, which contains information about military vehicles from the War Thunder game.

The dataset includes information about:
- Vehicle identifiers and names.
- Countries and vehicle types.
- Vehicle values and research requirements.
- Technical characteristics.
- Repair costs and times.
- Engine and aerodynamic parameters.

## Tools and Technologies

- **Python** — programming language.
- **Google Colab** — development environment.
- **Pandas** — data processing and analysis.
- **NumPy** — numerical operations.

## Practical Tasks

During the practical work, the following operations were performed:

1. Loading the dataset and preparing the working environment.
2. Grouping vehicles by type and calculating total and average values.
3. Grouping data by multiple columns and counting records.
4. Converting grouped results into a DataFrame.
5. Applying multiple aggregation functions using `agg()`.
6. Creating pivot tables using `pivot_table()`.
7. Building cross-tabulation tables using `crosstab()`.
8. Combining datasets using `merge()`.
9. Combining DataFrames using `concat()`.
10. Joining DataFrames by indexes using `join()` and calculating analytical indicators.

## Conclusion

During this practical work, data aggregation and grouping techniques using the Pandas library were studied and implemented.

Various methods were applied to analyze vehicle data, calculate statistical indicators, create pivot tables and combine DataFrames.

As a result, practical skills in processing, grouping, combining and analyzing structured datasets using Python were developed.
